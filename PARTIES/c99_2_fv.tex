Pour chaque géométrie, la convention de numérotation des faces est illustrée, puis la matrice de facteurs de vue théorique associée est donnée. Ces matrices sont également fournies en Section~\ref{anx:code_matrices} sous forme de code Python, prêtes à être réutilisées directement dans des scripts de vérification.
